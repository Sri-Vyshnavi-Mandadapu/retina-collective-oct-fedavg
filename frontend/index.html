THE VISION MODEL

DenseNet121.
Each layer builds
on what came before.

Within a dense block, a layer receives the feature maps produced by earlier layers. These features are concatenated, helping later layers reuse fine edges, textures and larger patterns.

Four dense blocks contain 6, 12, 24 and 16 dense layers. Each dense layer has two convolutions. Transition layers compress and downsample the features between blocks.

WHAT THIS PROJECT DOES

The global checkpoint
powers the prediction.

Your Colab notebook trains three client models from the same global initialization each round. Their parameters are averaged by image count. Your browser loads the exported, validation-selected global FedAvg checkpoint. The original trained weights power every result.

WHAT THE SIMULATION MEANS

A small window into
a much larger network.

This visualization uses three toy parameters and one gradient step on a toy quadratic loss. The real model has millions of parameters and learns from OCT images. The three clients in this project run sequentially on one Colab GPU; they are not deployed hospital systems.

RESEARCH BOUNDARIES

Useful evidence.
Honest limitations.

Federated averaging alone does not guarantee privacy. No differential privacy or secure aggregation is claimed. This four-class OCT task does not cover all retinal conditions and does not replace expert assessment.
